---
title: Boolean (Mantıksal) Veri Tipi
---

Go programlama dilinde `bool` _(boolean)_, yalnızca iki değere sahip bir veri türüdür: `true` _(doğru)_ ve `false` _(yanlış)_. Boolean veri türü, sıklıkla karar verme süreçlerinde ve mantıksal ifadelerin değerlendirilmesinde kullanılır. Boolean değerler, programların akışını kontrol etmek için önemlidir ve sıklıkla `if` ifadeleri, döngüler ve karşılaştırmalar gibi yapılarla birlikte kullanılır.

:::note
Bir `bool` veri tipinin `false`'tur.
:::

Örnek bir `bool` tanımlaması:

```go
var a bool // false
// veya
var a bool = true
// veya
var a = true
// veya
a := true
```
