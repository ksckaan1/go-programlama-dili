---
title: Bitsel Operatörler
---

| Operatör | Anlamı                     |
|----------|----------------------------|
| A&B      | AND(VE)                    |
| A&^B     | AND NOT(VE DEĞİL)          |
| ^B       | NOT(DEĞİL)                 |
| A\|B     | OR(VEYA)                   |
| A^B      | XOR(ÖZEL VEYA)             |
| A\<\<B   | Left Shift(Sola Kaydırma)  |
| A\>\>B   | Right Shift(Sağa Kaydırma) |


:::note[Daha fazla]
Bitsel Operatörler hakkında daha fazla detay istiyorsanız, [Go'da Bitwise (Bitsel) İşlemler](https://kaanksc.com/blog/go-da-bitwise-bitsel-islemler) adlı blog yazısını okuyabilirsiniz.
:::
